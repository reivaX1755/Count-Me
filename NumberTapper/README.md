# NumberTapper
1. Sube esta carpeta a un repo de GitHub.
2. Pestaña **Actions → Build APK** (se lanza sola con cada push). 
3. Descarga el artefacto `NumberTapper-debug-apk` (app-debug.apk) e instálalo.
4. Concede permisos en la app (accesibilidad, notificaciones, app a vigilar) y pulsa Iniciar.
Ajustes de zonas/tiempos: constantes al inicio de `CaptureService.kt`.
